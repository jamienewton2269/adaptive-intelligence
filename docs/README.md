## Safety
This initial release is **observation-only**. No commands are sent to lights or heating. Learning results are candidates for human review, not automatic rule changes.

## Installation
Add this repository as a custom integration repository in HACS, install Adaptive Intelligence, restart Home Assistant, then add the integration through Settings → Devices & services.

## Data
History is stored locally by Home Assistant in .storage. No cloud processing or outbound telemetry is required.
